    Waiting for the first call

    Repo Trace shows every request, and every line your app prints that is a JSON object with a trace key. To see your own steps and outside calls, log one finished call like this:

    console.log(JSON.stringify({ trace: "span", group: "ep_1", name: "write", svc: "claude", ms: 1200, ok: true }))

    Or a start and an end, to see it while it runs. The whole format is in docs/format.md, and lib/trace.ts writes it for you.
